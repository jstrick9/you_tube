# Validation audit — 4 Oct 2026

Brief: test and validate that the pipeline works correctly. Everything below was
**executed**, not reviewed. Where a claim could not be tested, it is listed as untested
rather than passed.

The headline finding is that a fix I shipped the previous day did not work, and its
test passed anyway.

> **Retrospective metric correction (9 Oct 2026):** this historical audit later referred to a 70% “completion gate.” That was not an official YouTube distribution gate, and historical `audienceWatchRatio` values are relative segment-watch ratios, not viewer-completion percentages. See [`MONETIZATION.md`](MONETIZATION.md); do not use the old wording or derived completion figures as evidence.

## 1. Headline finding: the series fix was in the wrong dict

**Claimed fixed 3 Oct. Still broken 4 Oct. Now actually fixed.**

A video published at 15:33 today — `FIELD #001` — on code that contained the fix, and
still recorded `series=None`. 0 of 32 history entries carry series data.

`package()` builds **two** dicts:

| dict | purpose | had the fix |
|---|---|---|
| `record` | written beside the video as the run artifact | yes |
| the return value | **what `run()` reads to build the history entry** | no |

The artifact therefore looked correct while history kept storing `None`, so
`episode_number()` — which derives the next number from that field — restarted every
run. That is why the channel published **CASE #002 and then FIELD #001**.

**The test failure matters more than the code failure.** The test searched
`pipeline.py` for the string of the fix. It could only prove the code existed, not that
it ran, so it passed for a day while the behaviour was broken.

Both fixed. The replacement calls `package()` against a stubbed renderer and asserts on
the returned dict. Verified by **removing the fix and watching the test fail**.

## 2. Suite-wide weakness found by generalising that

Audited all 35 tests in the credentials/provider suite for whether they exercise
behaviour or only read files. **7 asserted only on file contents.** Several are
legitimate — a workflow YAML *is* the artifact under test — but two described runtime
behaviour while only proving a placeholder existed in source: the lane voice and the
length budget.

Both rewritten to build a **real writer prompt** by stubbing the LLM mid-call. Verified
by mutation: removing `{lane_rule}` from the prompt makes the test fail.

The behaviour turned out to be correct. That is the point — the tests were weak, not
the code, and only running them could distinguish the two.

## 4. Not validated

Stated plainly, because an audit that only lists passes is advertising.

- **The series fix has not been through a live run.** It is verified by unit test and
  mutation, not in production. The next scheduled run is the real proof.
- **Internet Archive footage has never been selected.** The source is wired, licence-
  filtered and live-tested against the API, but Wikimedia has won every shot so far, so
  its end-to-end path is unexercised.
- **Pixazo has never been called in a run.** Correct by design — it is the last resort
  — but therefore unproven.
- **Episode numbers will still be low** for a while: the 32 existing entries hold no
  series data to count from.
- **Content performance was unmeasured.** The then-current report said no video met its
  70% target, but the report had mislabeled `audienceWatchRatio` as completion; that
  history cannot establish completion performance. The two 18.5s videos were also too
  recent to have matured. See the metric correction above.

## 5. Verdict

The machinery is sound and now has evidence behind each claim: 434 tests, 15 verified
model ids, three working vision providers, correct credentials, and published output
inside the target duration band with independent review recorded.

It is **not** "100% correct", and the audit earned that answer honestly — it found a
shipped fix that did nothing and a class of test that could not have detected it. The
remaining risk is concentrated in paths that have never executed, not in paths that
have been shown to fail.
